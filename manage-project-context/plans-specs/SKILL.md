# Brainstorming Ideas Into Designs Addendum

When superpowers brainstorming produces a design doc, save it to:

`.context/plans-specs/YYYY-MM-DD-<topic>-design.md`

The rest of the superpowers `brainstorming` skill applies, only the location to save the specs changes.
