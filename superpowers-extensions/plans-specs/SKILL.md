# Brainstorming Into Design Addendum

## Use with superpowers/brainstorming

When brainstorming produces design docs for this workflow setup, save them to:

`.context/plans-specs/YYYY-MM-DD-<topic>-design.md`

Commit the docs as part of the planning flow.

After writing the spec, present the complete artifact in the response and link to the exact file. Ask the user to approve the spec or request changes. Do not invoke `superpowers:writing-plans` until the user approves the spec; spec approval is the handoff into plan creation.
